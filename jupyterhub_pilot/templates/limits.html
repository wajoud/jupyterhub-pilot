RAM, CPU and terminal per user

Each value is taken from the first place that sets it: the user (this page), their team (Admin → Groups → the team → properties memory_max / cpu_quota), then resource_limits in hub_settings.json. Terminal off removes New → Terminal for that user; terminals_enabled: false in hub_settings.json turns it off for everyone. Saving a user replaces all three of their settings. Changes apply on the user's next server start.
